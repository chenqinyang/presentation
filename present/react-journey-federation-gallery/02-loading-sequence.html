READ THE RESPONSIBILITIES

Loading is not one operation.

01

A manifest describes; JavaScript executes.

The manifest is federation metadata. The runtime resolves a remote entry and the required JS/CSS assets, initializes sharing, and provides the exposed module. The sequence is conceptual; exact requests vary with caching, preloading, and bundling.

02

Pending and rejected need different UI.

Suspense displays the loading fallback while a lazy import is pending. A route-level Error Boundary handles a rejected lazy import or a rendering error. Business API errors require Journey-specific error handling.

03

Cached code is not preserved form state.

React.lazy caches its Promise and resolved result for that lazy component identity. A Journey can still unmount and lose transient state. Durable records live behind APIs; Host-owned shell state can persist across routes.

INTEGRATION EXCERPT / REACT

Keep the shell outside the slot boundary.

Define lazy components at module scope. The Host router selects a known Journey key; the remote provides a default-exported React component and never creates another React root inside the Host.

JourneyProps, loading UI, and JourneyErrorBoundary are application-owned contracts. The boundary shown here is a custom component implemented with React's Error Boundary lifecycle; its fallback prop is our convention.

Resetting a boundary does not retry a cached rejected lazy import. A fresh page load, or a deliberate new loader identity plus runtime recovery, is a separate recovery design.

import { lazy, Suspense } from 'react';
import { JourneyErrorBoundary } from './JourneyErrorBoundary';
import { JourneyLoading, RouteUnavailable } from './route-ui';
import type { JourneyProps } from './journey-contract';

// Explicit, known imports. Keep these identities at module scope.
const journeys = {
  onboarding: lazy(() => import('onboarding/Journey')),
  checkout: lazy(() => import('checkout/Journey')),
  account: lazy(() => import('account/Journey')),
};

type JourneyName = keyof typeof journeys;

export function JourneySlot({ name, journeyProps }: {
  name: JourneyName;
  journeyProps: JourneyProps;
}) {
  const Journey = journeys[name];
  return (
    <JourneyErrorBoundary key={name}
      fallback={<RouteUnavailable />}>
      <Suspense fallback={<JourneyLoading />}>
        <Journey {...journeyProps} />
      </Suspense>
    </JourneyErrorBoundary>
  );
}

// The Host's root, header, navigation, and router surround this slot.
// JourneyProps: basePath, locale, theme, session summary, navigate,
// onComplete, and an authenticated apiClient. Do not pass raw tokens.
// The custom boundary has no universal "retry import" behavior.
