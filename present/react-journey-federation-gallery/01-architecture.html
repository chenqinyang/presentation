DECISION / 01

A host that stays present

The host owns navigation and the route-level loading and error UI. This example selects loaded-first so an unused remote is not required to initialize the local shell.

DECISION / 02

Independent builds, explicit contracts

Each Journey exposes a React component. Props, callbacks, route prefixes and style conventions are application decisions; Module Federation does not create those contracts for you.

DECISION / 03

One page, shared responsibility

Shared packages help coordinate dependency identity. Remote code still shares the document and JavaScript environment. CSS scoping and trusted release validation remain necessary.

Connect the projects with Rsbuild.

Illustrative configuration · adapt paths and versions
HOST / rsbuild.config.tsConsumes three remotes
import { defineConfig } from '@rsbuild/core';
import { pluginReact } from '@rsbuild/plugin-react';
import { pluginModuleFederation }
  from '@module-federation/rsbuild-plugin';
import { sharedRuntime } from './federation.shared';

const release = (name: string) =>
  `${name}@https://cdn.example.com/${name}/v1/mf-manifest.json`;

export default defineConfig({
  plugins: [
    pluginReact(),
    pluginModuleFederation({
      name: 'host_ui',
      shareStrategy: 'loaded-first',
      remotes: {
        onboarding: release('onboarding'),
        checkout: release('checkout'),
        account: release('account'),
      },
      shared: sharedRuntime,
    }),
  ],
});
CHECKOUT / rsbuild.config.tsExposes a Journey
import { defineConfig } from '@rsbuild/core';
import { pluginReact } from '@rsbuild/plugin-react';
import { pluginModuleFederation }
  from '@module-federation/rsbuild-plugin';
import { sharedRuntime } from './federation.shared';

export default defineConfig({
  output: {
    assetPrefix:
      'https://cdn.example.com/checkout/v1/',
  },
  plugins: [
    pluginReact(),
    pluginModuleFederation({
      name: 'checkout',
      manifest: true,
      shareStrategy: 'loaded-first',
      exposes: {
        './Journey': './src/Journey.tsx',
      },
      shared: sharedRuntime,
    }),
  ],
});

Use the enhanced plugin once per build; do not also configure the native federation option for the same container. sharedRuntime above is a project-owned config helper copied into each build: it declares aligned singleton entries for React and ReactDOM and their used subpaths. It shares packages, not user session state. Use an async host bootstrap, e.g. import('./bootstrap'), before rendering the shell.

Shared runtime helper used by both configurations
// federation.shared.ts — copy this policy into every project.
// All projects must use aligned, tested package versions.
import pkg from './package.json';

export const sharedRuntime = {
  react: { singleton: true, requiredVersion: pkg.dependencies.react },
  'react/': { singleton: true, requiredVersion: pkg.dependencies.react },
  'react-dom': {
    singleton: true, requiredVersion: pkg.dependencies['react-dom'],
  },
  'react-dom/': {
    singleton: true, requiredVersion: pkg.dependencies['react-dom'],
  },
};

Trailing-slash keys cover package subpaths, such as React JSX runtimes and ReactDOM client imports. Validate behavior with your installed plugin version. See shared dependency configuration.
